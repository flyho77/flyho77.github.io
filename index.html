The Shift Ladder

합성 공격 데이터로 끌어올린 탐지율은 어디까지 통할까요. 평가 환경을 사다리처럼 한 칸씩 옮기며, 성능 향상이 남는 지점과 사라지는 지점을 찾았습니다.

WISA 2026제1저자재현 자료 공개 · MIT

문제 정의
차량 내부 네트워크(CAN)의 침입 탐지 모델은 공격 데이터가 부족해, 규칙으로 만든 합성 공격으로 학습 데이터를 보강하곤 합니다. 그렇게 얻은 성능 향상이 합성 데이터와 닮은 평가에서만 나타나는지, 다른 차량과 수집 환경에서도 유지되는지는 따로 확인해야 합니다.
역할
제1저자로 평가 단계를 나눈 실험을 설계했습니다. 전처리, 합성 공격 생성, 학습, 평가로 이어지는 파이프라인을 구현하고, 실험 계획과 결과표, 실행 기록을 재현 자료로 공개했습니다.
기술
  • Python 3.12
  • PyTorch
  • scikit-learn
  • pandas
  • NumPy
  • PyArrow
  • Matplotlib

학습: Car-Hacking · 외부 평가: OTIDS, ROAD, can-train-and-test

결과
  • +50.25%p고정 합성 변형에서 공격 탐지율이 49.74%에서 99.99%로 올랐습니다. 학습 업데이트 횟수를 7,992회로 맞춘 비교입니다.
  • +16.90%p합성 조건을 바꾼 민감도 평가에서도 55.10%에서 72.00%로 올랐지만 폭은 줄었습니다.
  • ≈100%외부 데이터 3종에서는 정상 구간 거의 전부에 경보가 울렸습니다. 오탐률을 1% 이하로 묶으면 탐지율은 0%였습니다.

합성 보강의 이득은 생성 규칙과 가까운 평가에 머물렀고, 외부 데이터로는 이어지지 않았습니다.

결과 데모 평가 단계를 골라 보세요

평가 단계

공격 탐지율 · 높을수록 좋음

고정 합성 변형

동일한 7,992회 학습 업데이트 · 시드 5개 평균

  • 실측 데이터만49.74%
  • 실측 공격 재표집 +30%48.74%
  • Rule +30% (합성 보강)99.99%

합성 데이터로 보강한 모델은 실측 데이터만 쓴 모델보다 탐지율이 50.25%p 높았습니다.

Where the Gates Leak

같은 도구 호출을 두고 보안 정책마다 판단이 어떻게 갈리는지, 호출 기록 286건을 고정해 재현했습니다.

문제 정의
에이전트의 도구 호출을 허용·차단하는 정책 게이트는 제품마다 판단이 다릅니다. 모델을 다시 실행하면 호출 내용이 매번 달라져 같은 조건에서 비교하기 어렵습니다.
역할
제1저자. AgentDojo에 기록된 호출을 고정하고, 모델 없이 각 게이트에 그대로 재생하는 평가를 설계했습니다.
기술
Python 3.12 · AgentDojo · CaMeL · Progent · 해시로 고정한 실행 기록
결과
위험한 흐름 207건 중 Progent는 시작 정책에서 48건, 완성 정책에서 36건을 허용했습니다. CaMeL은 한 건도 허용하지 않았지만 정상 작업 35건 중 8건만 통과시켰습니다.

Progent Update Integrity

정책 변경 검사기를 고쳐, 권한 확대를 잘못 승인한 사례를 120건에서 0건으로 줄였습니다.

문제 정의
에이전트 권한 정책 Progent는 정책을 바꿀 때 권한이 줄어드는 변경만 승인합니다. 이 검사가 실제로는 권한을 넓히는 변경을 통과시키는지 확인했습니다.
역할
정책 변경을 검사하는 코드를 수정하고, 고정한 평가 세트에 기존 검사와 수정본을 함께 적용해 검증했습니다.
기술
Python 3.12 · JSON Schema (jsonschema) · Progent · 모델 호출 없는 결정적 평가
결과
기존 검사는 권한을 넓히는 변경 437건 중 376건을 승인했습니다. 수정본은 평가 세트(C4) 136건에서 잘못된 승인이 120건(v1)에서 0건(v2)이 됐습니다.
